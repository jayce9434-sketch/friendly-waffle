# Collision Ring

A simple browser physics toy:

- Starts with 2 balls
- Every new ball-to-ball contact spawns 1 new ball
- All balls shrink as the population rises
- Hard minimum ball radius prevents them from becoming invisible
- Live ball count / spawn rate / collision stats
- Ball-to-ball physics
- Ring-wall bouncing
- Mobile-friendly canvas
- Tiny generated collision sound using Web Audio
- No external assets

## Run

Open `index.html` locally, or upload all files to the root of a GitHub Pages repository.

## Files

- `index.html`
- `style.css`
- `game.js`
- `README.md`

All files are root-level. No folders.
